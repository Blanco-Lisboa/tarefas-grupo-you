# Grade de conteúdo (nome provisório)

Sistema do Natham e do Matheus para organizar os conteúdos de todas as empresas do Grupo You (começa com Beec e You): calendário, tarefas, quadro por etapa e pastas de arquivos. Escopo completo em `PRODUCT.md`.

## Executar

```bash
npm install
npm run dev      # abre em http://localhost:3000
npm run check    # lint, tipos, regras, testes e build
```

Fase 1: tudo roda com dados de exemplo em memória. Nenhuma credencial é necessária.

## Documentação

- `PRODUCT.md`: o que é e o que não é.
- `docs/architecture.md`: pastas, camada de dados e filtro de empresa.
- `docs/design.md`: identidade visual Beec e exceções aprovadas.
- `docs/onboarding.md`, `docs/quality.md`, `docs/setup.md`: preparação, checks e evidências do bootstrap.
- `docs/levas/`: pedidos e brief do Natham, com estado.
- `ORIGEM-DA-IDENTIDADE.md`: de onde veio cada arquivo da identidade.
